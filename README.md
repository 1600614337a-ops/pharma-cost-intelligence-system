# 制药成本智能分析系统

本仓库为“基于RAG与大模型的制药企业产品成本智能分析报告系统”的公开代码仓库。系统以确定性成本计算为事实底座，结合受治理的混合检索、受控大模型叙述、Word/PDF报告和人工审批后的模拟RPA整改闭环。

## 公开仓库与受限数据

公开仓库只包含自研代码、启动文件、依赖清单、技术方案和客观评测说明，不包含：

- 赛题CSV、企业知识文档、报告模板和派生知识索引；
- API Key、`.env`、本机加密凭据；
- 生成报告、运行日志、审核数据库和RPA回执。

这些内容受赛题数据使用范围约束。评委或验收人员应从组委会提供的数据包或正式受控提交包中取得运行数据，并把以下目录放到仓库根目录：

```text
01_成本明细数据/
02_行业参考数据/
03_制药知识文档/
04_报告模板/
06_知识证据索引/
```

其中 `06_知识证据索引/` 是由受限知识文档在本地生成的派生运行资产，不在公开仓库发布。正式提交包已经包含经过验收的索引；若重新构建，必须同时具备项目治理目录中登记的全部知识文档。

## 跨环境一键启动（推荐）

适用环境：Windows、macOS或Linux，要求安装 Docker Desktop 或 Docker Engine（含 Compose v2）。Docker镜像内固定 Python、LibreOffice、Poppler和中文字体，避免不同电脑的Word/PDF渲染环境漂移。

1. 将上述受限数据目录放到仓库根目录。
2. 启动系统：

   - Windows：双击 `启动跨环境演示.cmd`；
   - macOS/Linux：执行 `./start-docker.sh`；
   - 通用命令：`docker compose up --build -d`。

3. 首次构建完成后访问 `http://127.0.0.1:8080`。
4. 停止系统：Windows双击 `停止跨环境演示.cmd`，或执行 `docker compose down`。

启动过程会先运行失败即停的预检，核对10份CSV、知识索引、107字段报告契约、Word模板和LibreOffice；任一关键依赖缺失时不会带病启动。

### 通义千问（可选）

未配置API Key时，确定性分析、看板、Word/PDF和整改候选仍可运行，大模型叙述自动回退。需要验证通义千问时：

1. 将 `.env.example` 复制为 `.env`；
2. 把 `COST_LLM_ENABLED` 改为 `true`；
3. 只在本机 `.env` 中填写 `COST_LLM_API_KEY`；
4. 重新执行 `docker compose up --build -d`。

`.env` 已被Git忽略，禁止提交真实密钥。

## Windows本机快速启动（备选）

已安装 Python 3.11+ 和 LibreOffice时，可以双击 `启动演示系统.cmd`；首次运行会自动创建 `.venv` 并安装 `requirements.txt`，避免目标电脑因缺少 `pydantic` 等依赖而启动失败。默认端口被占用时，脚本会自动选择下一组可用端口并在窗口中输出实际 `Dashboard` 地址。首次启用通义千问可运行 `配置通义千问API.cmd`，密钥由当前Windows用户DPAPI加密保存。该路径便于现场演示，但跨环境复现以Docker方式为准。

## 核心功能

- 月度、季度和专题三类分析；
- 环比、同比、预算偏差、成本要素贡献度与两厂对标；
- 趋势图、瀑布图、总成本桥接、成本结构和三维交叉热力图；
- 产品配方、工艺、设备、GMP、行业基准、对标基线和历史异常的混合RAG；
- 107字段报告契约，统一生成Word和PDF；
- 大模型只改写受控叙述字段，失败或越界时确定性回退；
- 整改任务JSON、人工审批、幂等提交和模拟RPA回执。

## 安全边界

- 默认仅绑定本机 `127.0.0.1:8080`，不提供匿名公网隧道；
- 原始数据与模板只读，报告、审计和任务状态写入独立输出目录；
- 大模型不计算或改写成本事实、引用、报告标识与审批状态；
- RPA候选必须由人工填写责任人、部门和截止时间并明确确认后才能模拟发送。

本仓库用于竞赛评审与技术复现。正式企业上线需要另行配置身份认证、固定HTTPS域名、持久化数据库、备份和企业级密钥管理。
