# 一键启动与演示前预检报告

> 版本：V1.1  
> 实测日期：2026-08-25  
> 本机环境：Windows、Python 3.12.6、LibreOffice 26.2.5.2

## 1. 使用方式

### 1.1 跨环境Docker启动（推荐）

在Windows、macOS或Linux安装Docker Desktop或Docker Engine（Compose v2），并将受控数据目录放在仓库根目录后执行：

```bash
docker compose up --build -d
```

Windows可双击 `启动跨环境演示.cmd`，macOS/Linux可执行 `./start-docker.sh`。镜像固定Python 3.12、LibreOffice、Poppler和Noto CJK字体，容器先预检再启动Web与模拟RPA，浏览器访问 `http://127.0.0.1:8080`。停止时执行 `docker compose down`。

### 1.2 Windows本机启动（备选）

首次运行先安装依赖：

```powershell
python -m pip install -r requirements.txt
```

随后可直接双击根目录文件：

| 文件 | 作用 |
|---|---|
| `演示前预检.cmd` | 只检查环境、数据、索引、模板、LibreOffice和端口，不启动服务 |
| `启动演示系统.cmd` | 预检通过后启动Web和本机模拟RPA，并打开浏览器 |
| `停止演示系统.cmd` | 只停止由启动脚本登记且命令行匹配的两个项目进程 |

启动后访问 `http://127.0.0.1:8080`。Web与模拟RPA分别监听 `127.0.0.1:8080` 和 `127.0.0.1:8090`，不会绑定 `0.0.0.0`。

PowerShell命令行方式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/preflight_demo.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_demo.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop_demo.ps1
```

不希望自动打开浏览器时，对启动脚本增加 `-NoBrowser`。

## 2. 预检项目

启动采用失败即停策略，任一必要检查失败都不会留下半启动服务。

| 检查 | 通过条件 | 2026-08-03实测 |
|---|---|---|
| Python运行时 | Python 3.11或更高 | PASS，3.12.6 |
| 关键文件 | 8项代码、模板、索引、前端和自研模拟RPA文件存在 | PASS，8/8 |
| 源数据质量 | 无阻断错误 | PASS，`PASS_WITH_WARNING`，10个CSV、334条有效原始记录 |
| 知识索引 | 可返回受治理证据 | PASS，hybrid，BM25=0.70、向量=0.30 |
| 报告契约 | 银黄口服液黄金场景107字段全部有效 | PASS，CA-202605-YH-001 |
| LibreOffice | 可执行并返回版本 | PASS，26.2.5.2 |
| 本机端口 | 8080和8090可绑定 | PASS |

`PASS_WITH_WARNING` 表示没有阻断分析的错误，但仍保留已治理的知识冲突、映射或基准缺失等警告；系统不会把警告静默改写为事实。

## 3. 进程、日志与恢复

运行状态保存在 `tmp/demo_runtime/processes.json`，包括Web/RPA PID、端口、URL和启停时间。日志位于：

- `tmp/demo_runtime/dashboard.out.log`
- `tmp/demo_runtime/dashboard.err.log`
- `tmp/demo_runtime/mock-rpa.out.log`
- `tmp/demo_runtime/mock-rpa.err.log`
- `tmp/demo_runtime/preflight.json`

启动脚本轮询两个 `/health` 接口，超时或进程提前退出时会停止已启动的另一服务并返回失败。停止脚本先通过 `Win32_Process` 核对PID对应的命令行标识，再执行停止，避免PID被其他程序复用后误杀。

## 5. 常见失败处理

| 现象 | 处理 |
|---|---|
| 提示端口被占用 | 先运行停止脚本；若仍占用，查看预检提示并关闭实际占用程序，不强制杀进程 |
| LibreOffice检查失败 | 确认已安装并可从常见安装目录或PATH找到 `soffice.exe` |
| 知识索引失败 | 按README命令重建 `06_知识证据索引` 后重新预检 |
| 数据质量失败 | 查看阻断错误，修正副本或处理层；不得直接覆盖原始文件 |
| RPA提交连接失败 | 确认8090健康检查和 `mock-rpa.err.log`，服务恢复后在页面重试 |
