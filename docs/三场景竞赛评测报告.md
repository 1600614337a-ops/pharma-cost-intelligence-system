## 1. 评测方法

评测脚本对每个场景重新加载原始CSV和知识索引，构建完整报告契约，并逐项核对：

1. 报告契约状态、107个字段、5张受保护动态表和1张受控建议表；
2. 黄金金额、百分比、贡献度及两厂差异；
3. 必需证据、缺失指标“暂无数据”和8类知识引用；
4. README替代数值、采购因果和设备故障错误因果等禁用结论；
5. 受控改进建议、整改候选数量、来源追溯、人工审批边界和模拟RPA HTTP提交；
6. 实际调用通义千问后，100个非叙述字段、确定性事实表、知识引用和黄金数值不被模型修改。

执行命令：

```powershell
python scripts/competition_evaluation.py --project-root . --execute-rpa --output output/evaluation/三场景自动评测结果.json
.\scripts\run_llm_golden_evaluation.ps1
```

## 3. 场景结果

### 3.1 银黄口服液，2026-05 对比 2026-04

| 验收项 | 标准结果 | 结论 |
|---|---:|---|
| 单位成本 | 10.90→11.21元/盒 | 增加0.31元/盒，环比2.84% |
| 材料对总成本变动贡献度 | 67.09% | 赛题主口径；材料总成本增加34,000.00元 |
| 金银花单位消耗成本 | +0.15元/盒 | 由结构化材料明细重算 |
| 金银花市场价 | 130→138元/kg | 市场环比6.15% |
| 两厂单位成本差异 | -0.39元/盒 | 一厂低于二厂，成本更有利 |

允许结论：材料是总成本变动和单位成本变动中的最大成本要素，金银花单位消耗成本与市场价同期上升。不得把市场行情写成企业实际采购价或已经证实的采购因果。

自动结果：PASS；模拟RPA：`sent`，HTTP 200。
